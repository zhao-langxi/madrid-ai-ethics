# From Madrid to ServeIT

**Status:** Bridge note · portfolio throughline  
**Connects:** Study abroad reflection → IU nonprofit clinic work → public-interest tech career frame

## One instinct, different rooms

Portfolio throughline (public): drawn to the unglamorous parts of systems everyone else skips ... the handoff after the demo, the lease clause nobody reads until it matters, the student who needs an honest answer instead of a polished one.

Madrid did not invent that instinct. It **stress-tested** it in a country where I was the outsider. ServeIT applies the same instinct for Bloomington community partners who cannot keep a developer on retainer.

## What transferred

| Madrid observation | ServeIT / Informatics practice |
|--------------------|--------------------------------|
| Forms assume you already belong | WCAG + plain-language handoffs for partner sites |
| Language as access control | Mixed-language DOM, `lang` markup, i18n note on portfolio |
| Unwritten process steps | Pre-ship checklists, chunk maps, staff-maintainable Cascade builds |
| AI marketed before basics work | ServeAI: responsible adoption, accessibility alongside automation |
| EU governance vocabulary | Useful for reading public AI policy ... not a separate career lane |
