# Evaluation bar · current vs future

**Honest status:** This repo is **reflective practice + pattern library + reusable artifact**. It is **not** yet a formal impossibility proof, ablation study, or controlled user study against SOTA baselines.

## Three pillars (how they apply here)

### 1. Bounded proofs / non-existence (practice-gap framing)

For this claim, “non-existence” is **not** “friction does not exist.” It is a **gap in design practice**: outsider friction is often treated as a post-launch accessibility fix rather than a first-class requirement for civic digital services and public-interest AI.

| Stronger evidence later (not claimed now) | Role |
|-------------------------------------------|------|
| Structured outsider observation protocol on N civic flows | Tests whether disadvantage recurs beyond anecdote |
| Happy-path / WCAG review vs Outsider Impact Review on the same 2+ systems | Tests whether the artifact finds gaps ordinary review misses |
| Pre-registered comparison of accountability features when outsider checks are required pre-ship | Tests the “first-class requirement” half of the claim |

**Falsifiability:** See [`CLAIM.md`](./CLAIM.md). Absence of papers on this exact phrasing is **not** proof of novelty or truth.
